## 🐋 策展主題與核心理念：『夢想共聲 ５２赫茲』
在深邃浩瀚的教育汪洋中，每位初出茅廬的實習老師，如同那隻吟唱在 **52 赫茲（52Hz）** 頻率的深海藍鯨。因為頻率獨特，起初總在茫茫深海中獨自探索；然而，走入四維國小這座充滿包容與溫度的教育綠洲，**24 位高師大實習教師**、**12 位四維國小輔導導師** 與全校學童相遇，在三週的晨昏相伴、備課試教與公開演示中，我們找到了彼此的音頻——**「同頻共振」**，齊聲奏響了最真摯動人的教育交響樂。

## 🛡️ 個人資料隱私保護（去個資處理）
本成果展網頁全面落實 **教育部及個人資料保護規範**：
- **移除項目**：已全數遮蔽並移除全體師長與實習教師之個人手機號碼、電話分機、電子郵件信箱（Email，包含高師大校園信箱、Gmail、Yahoo 等）以及學號等私人資訊。
- **保留項目**：保留學術專業、師資所屬系所／學位、實習組別、班級代號（2-7、4-6、6-10 等）、教學演示科目單元、教案設計重點與實習反思金句，確保隱私安全且充分展現教學專業風采。

## 🎨 網站亮點與視覺美學特色
1. **深海音波流體視覺美學**：
   - 採用星夜深藍（`#060d19`）、微光青藍（`#00d2ff`）、柔和月光金（`#f6d365`）與毛玻璃擬態（Glassmorphism）設計。
   - 背景即時 Canvas 渲染 52Hz 生物微光粒子與深海波浪起伏動畫。
2. **52Hz 夢想共鳴 Web Audio 合成器**：
   - 內建瀏覽器原生 Web Audio API，點擊導覽列「🎧 聆聽 52Hz 夢想共鳴」即可即時播放專屬 52Hz 基礎純音與 104Hz 溫潤泛音，伴隨聲波跳動特效。
3. **休業式 33 張官方精華攝影特展**：
   - 完整收錄休業式 33 張高解析度官方紀實照片，包含比心比讚全體大合照、雙校校長與教授勉勵、實習幹部呈獻手寫愛心感恩展板、實習生代表心得分享、李沛錞親繪 52Hz 藍鯨主視覺卡等。
   - 支援 8 大主題分類篩選（合照紀念、師長風采、雙校領航、感恩呈獻、心得發表、典禮盛況、幕後籌備、主視覺象徵）與高解析燈箱（Lightbox）全螢幕預覽。
4. **12 個實習班級．24 位實習教師群像展**：
   - 橫跨低年級（2年級）、中年級（4年級）、高年級（5-6年級）三大年段。
   - 支援年段快速標籤篩選與**即時關鍵字搜尋**（可搜尋教師姓名、學系、單元、班級代號）。
   - 每位實習老師均收錄其系所、角色、公開授課演示單元、教學反思金句與班級特色。
5. **多元實習珍藏檔案庫（120+ 張精彩剪影）**：
   - 始業式啟航紀實（36張）
   - 初入班對話見習（15張）
   - 課堂試教與觀議課現場（50張）
   - 406班全體學童親手手繪寫給沛錞老師的暖心感恩卡（24張）
6. **試教智慧與經典教案**：
   - 整理數學與國語試教評委提問與反思（「製造需求而非直給錦囊」、「一問多答促進同儕互動」、「把麥克風交給孩子」）。
7. **手札共鳴輪播卡**：
   - 蔡佳芸「探星者」、徐秉鴻「教育赤子心」、蔡承軒「點燃火種」、鄭凱瀚「教室劇場」、易冠蓁「29張專屬小卡」等觸動人心的反思輪播。

## 🚀 如何啟動與瀏覽網頁

### 方式一：透過本地伺服器開啟（推薦，音效與功能最完整）
伺服器已在背景運行，或可於專案目錄執行：
```powershell
node server.js
```
接著在瀏覽器打開：
👉 **http://localhost:5252**

### 方式二：直接離線開啟
在檔案總管中直接雙擊開啟：
👉 `C:\Users\user\.gemini\antigravity\scratch\nknu-swps-internship-exhibition\index.html`  
*(專案已內建 `data.js`，不需任何伺服器或聯網即可離線流暢運作)*
